__ПРОЕКТ СОСТОИТ ИЗ 4 МОДУЛЕЙ:__
1. api.py — реализует паттерн «Адаптер» и абстрактный класс для работы со сторонними сетевыми API
   (Nominatim и OpenSky Network) с механизмом защиты от сетевых блокировок.
2. models.py — инкапсулирует данные о воздушном судне в объекты класса Aeroplane,
   осуществляет валидацию типов и перегрузку операторов сравнения (<, >, ==) для анализа скорости и высоты полёта.
3. db_manager.py — отвечает за всю логику работы с базой данных PostgreSQL.
4. main.py — организует интерактивный CLI-интерфейс для конечного пользователя.

__СТРУКТУРА ЭЛЕМЕНТОВ:__
```
📄 api.py — интеграция с внешними сервисами.
📄 models.py — объектные модели самолетов.
📄 db_manager.py — сохранение и фильтрация в таблицах базы данных PostgreSQL.
📄 main.py — запуск программы и меню пользователя.
📁 tests/ — пакет модулей автоматических тестов проекта.
```

__шаг 1__
1. Создан модуль api.py    
2. Абстрактный класс BaseAPIAdapter(ABC), задает жесткую структуру.
3. Основной класс объявлен как class APIAdapter(BaseAPIAdapter): — это наследование в рамках паттерна Адаптер.
4. Получаем координаты через Nominatim
5. Если сервер не дал координаты (ошибка) используем режим офлайн - локальный справочник
6. Вывод координат
7. Отпрвляем запрос в OpenSky

__шаг 2__
1. Создан модуль models.py
2. Реализовани класс: Aeroplane с валидацией входных данных
3. Программа оперирует не абстрактными индексами, а понятными свойствами объектов
   (plane.velocity, plane.altitude).
4. Реализована валидация (защита от значений None, когда самолет стоит на взлетной полосе).
5. Класс Aeroplane включает методы:
   - Сравнение ПО ВЫСОТЕ
   - Сравнение ПО СКОРОСТИ
     
__шаг 3__
1. Модуль db_manager.py
2. Инициализация менеджера базы данных.
3. Создает и очищает таблицы стран и самолетов.
4. Сохраняет страну и список объектов самолетов Aeroplane в базу данных.
5. get_countries_and_aeroplanes_count() — получает список всех стран и количество самолетов в их воздушных пространствах.
6. get_all_aeroplanes() — получает список всех воздушных судов.
7. get_avg_speed() — получает среднюю скорость по самолетам.
8. get_aeroplanes_with_higher_speed() — получает список всех самолетов, у которых скорость выше средней.
9. get_aeroplanes_with_keyword() — получает список всех самолетов, в позывном которых содержатся переданные в метод символы.

__шаг 4__
1. Создан модуль main.py
2. Консольный интерактивный интерфейс: Меню бесконечно крутится в цикле while True,
   пока пользователь явно не выберет пункт 5.
3. Инициализация окружения (python-dotenv): Безопасно загружает скрытые параметры подключения к PostgreSQL (пароль, порт, хост) из файла .env.
4. Автоматический бутстрап (наполнение БД): При старте программы запускает цикл по 10 обязательным странам из ТЗ, запрашивает по ним данные через API и передает их в DBManager для сохранения в базу данных.
5. Консольный интерфейс (CLI): Реализует интерактивное текстовое меню для пользователя, обрабатывает ввод и выводит отформатированные результаты аналитических SQL-запросов.
